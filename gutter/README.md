# Gutter

Gutter is a self-hosted comic release tracker for a Komga library. It matches followed series against Metron, sends release and digest notifications through ntfy, and lets you send missing issues to Kapowarr.

All integrations, schedules, credentials, and recommendation controls are configured from the Home Assistant app's Configuration tab. Gutter supports Home Assistant systems using `amd64` and `aarch64`.

See the **Documentation** tab after installation for setup and networking guidance.
